# 0002. 在线 Metadata 源：仅官方 API 三件套，网易云源远期评估

日期：2026-09-09
状态：已接受

Windy Concert 的目标用户以华语听众为主，而 MusicBrainz 对华语音乐覆盖率一般。即便如此，0.5 版在线补全仍只集成 MusicBrainz、Cover Art Archive、Last.fm 三家官方 API，网易云等国内源列为远期可选项（需先评估接口合规性与稳定性）。理由：三家提供面向播放器/Tagger 场景的公开 API 与明确的 MBID 实体体系，无法律与封禁风险；逆向第三方接口随时可能失效并带来合规争议。代价是华语封面/元数据补全率不足，此限制在需求文档中如实声明，由用户提供本地 cover.jpg 的发现规则部分弥补。
